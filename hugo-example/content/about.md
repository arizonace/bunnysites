Northstar Journal is a deliberately small publishing space. It is an example site built with Hugo: no database, no application server, and no moving parts once it is published.

The design favors generous reading space, plain language, and a useful amount of character. Everything you need to edit the pages, add notes, and build the finished static site lives in this folder.

## A simple publishing rhythm

Write a Markdown file, give it a title and date, then run Hugo. The resulting files are ready for any standard web server to deliver.
